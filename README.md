## “三网优化”到底优化了什么

绿云说的三网优化，落在东京机房就是两条具体线路：IIJ（AS2497，日本骨干运营商）和软银。这两条线路的价值取决于你的宽带属于哪家运营商，差别相当大。

先看 IIJ 线路的实测数据。电信 163 用户走 IIJ 后接入电信 AS4134 直连回国，上海电信延迟约 29–68ms，测速下行跑到 6227Mbps；北京电信回程走 IIJ（AS2497）直连上海再转北京，约 79ms。联通普通用户（4837）就没这个待遇了，回程绕美国 Level3 再转 4837，延迟 133–157ms；联通 9929 用户倒是能走 IIJ，前段延迟不高。移动用户走 CMI 回国，延迟大约 59–118ms。

软银线路的逻辑不同：三网去回程都走 SoftBank。digvps 在 2026 年 7 月测的软银款大盘机，三网去回程均显示 SoftBank。它的好处是路径统一、晚高峰相对稳定，坏处是软银线路的 IP 段被墙概率比 IIJ 高，nodeseek 上 2026 年 10 月的四节点对比里直接写明“软银 IP 被墙风险高”。

另外要纠正一个常见误解：三网优化不等于三网全部直连。同一台东京 IIJ 机器，电信是直连，联通普通宽带照样绕美国。所以买之前最好先搞清楚自己家宽带是哪家、走不走 9929/CN2，别看到“三网优化”四个字就默认自己那一路也能跑满。
